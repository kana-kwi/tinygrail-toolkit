# 一、组件「简介」（填在组件信息里，纯文本）

把小圣杯日常要做的事收进一个浮窗：筛塔、按等级筛持股、查幻想乡持仓、管理收藏夹（多夹 / 星标 / 一键导入）、批量道具与一键冲星、ICO 自动注资、账本收支分析，还能把喜欢的圣殿置顶到个人页最前面（置顶 / 置底都能直接从收藏夹点选）。新旧两版小圣杯通用，收藏与置顶支持同步码 / 组件云设置跨设备同步。

# 二、小组介绍帖（BBCode，可直接粘贴）

标题：<b>【组件】小圣杯工具箱 —— 选塔 / 持股 / 道具 / ICO / 账本，一个浮窗全搞定</b>

正文：

[b]这是什么[/b]

一个常驻在页面上的小浮窗（右下角「工具箱」，快捷键 Alt+T），把小圣杯日常要做的事集中到一起。旧版和新版都能用，装好即生效，不用每次去开。

[b]它做什么[/b]

[b]① 选塔[/b]
· 按固定资产阈值筛塔（默认 < 250），可叠加「塔图换没换过」
· 结果直接是角色列表，点名字就能进角色页
· 已 LINK 的塔、以及站点判定「已损坏」不显示的塔（固资 < 250）也会一起算进来，不会少塔
· 「角色列表」里勾上「只筛自己圣殿」，就变成搜自己的圣殿：给你一串角色 ID，只列其中你建过塔的
· 筛出来的如果是自己的塔，名字右边有个图钉：点一下就把这座塔**排到个人圣殿页第 1 页最前面**
  （只改显示顺序，不动置顶 / 置底名单，想撤销才撤销、不会自己过期）。可以同时定位好几座，最近点的排最前；
  顶部提示条会写「已定位 N 座」，点「取消全部定位」一起撤销（列表当场恢复原顺序）；图钉变粉时再点一下就是取消那一座。
  个人圣殿页没打开的话，点开自己的头像后会自动接着排好

[b]② 查仓[/b]
· 持股：按等级区间 / 最少持股筛，每行直接写「距下一级还差多少股」
· 几千只持仓也能秒搜，搜索优先于所有筛选条件
· 幻想乡：某个角色被幻想乡持有多少、占多少比例

[b]③ 收藏夹[/b]
· 同一个角色可以同时进多个收藏夹，列表里用标签显示，点标签就能换夹、加夹
· 每行直接看：持股 / 我这座塔的固资（当前 / 上限）/ 英灵殿
· 角色页有个小 ★，点一下收进指定夹；填 ID 或名字都有候选提示
· 支持一键导入小圣杯自带的收藏，自动跳过未上市与已退市（ST 会保留）

[b]④ 道具[/b]
· 混沌魔方 / 虚空道标 / 鲤鱼之眼一键连用，可设炮塔、目标与次数，撞到每日上限自动停
· 一键冲星：填角色和数量，自动按这座塔的固资上限分批，收尾可选「补满 / 补到 250 / 不补」
· 星光碎片：填目标塔，自动列出自己有活股的持仓，按持股从多到少排列，可按等级筛

[b]⑤ ICO[/b]
· 列出自己参与注资的 ICO，按剩余结束时间排序，快到期的在最前
· 可设目标等级 + 自动注资：结束前 N 分钟还没到就补一次，补完自动收手，不会重复注

[b]⑥ 圣殿[/b]
· 个人页圣殿置顶：站点按固定资产上限排、还分页，喜欢的塔容易被挤到第 7 页。这里可以自己排一份名单，置顶的塔按你的顺序排在第一页最前，支持拖拽调序
· 置顶 / 置底 / 调顺序都是**点完当场生效**：个人圣殿页开着就立刻重排，不用再刷新
· 置顶 / 置底的输入框右边有枚 ★：点开收藏夹，点一个角色就直接置顶 / 置底一个，可以连着点
· 置底：把不想要的角色排到最后一页最后一个，和置顶互斥（同一个角色只会在一份名单里）
· 无缝 link 图、个人页每行 4 / 5 / 6 个
· LINK 圣殿可以互换左右顺序，角色页和连接页一起跟着变

[b]⑦ 账本[/b]
· 资金收支、股数增减、圣殿固资三个维度按来源分类汇总
· 带账户余额走势、角色持股排行、被道标命中的塔汇总

[b]⑧ 顺手的小东西[/b]
· 随手记：标题栏的小书图标，点开就是一张便签，自动保存
· 塔图工具：自己的塔可以换图 / 裁剪，别人的塔可以一键复制过来；GIF 可以逐帧选一张当封面贴上
  （「只更换封面」默认勾上 = 只在本机贴图，站点上的原 GIF 一个字节都不动），新版旧版都能贴。
  贴图只改列表里的封面，点开塔图看到的还是站点原来那张
· 日间 / 夜间模式，窗口可拖动，位置会记住

[b]跨设备[/b]

收藏夹和置顶名单默认存在本机，可以用「同步码」导出、在另一台设备导入；在 Bangumi 组件环境下还会自动存进组件云设置，换设备打开就同步，不用手动导。

[b]几点提醒[/b]

· 道具、冲星、ICO 注资都是[b]真实操作[/b]，会消耗固资和资金，点之前看清楚
· 改「每行几个」要刷新个人页才生效（置顶 / 置底 / 定位不用，点完当场重排）
· 只改你自己看到的画面，不动站点数据，也不影响别人的显示
· 停用组件会清掉云设置里的那份数据，重要的还是建议留一份同步码

用着有问题、或者想要什么功能，直接回帖说就行。
