# 小圣杯工具箱 · tinygrail-toolkit

Bangumi「小圣杯」的单文件超合金组件，新旧两版页面通用。一个浮窗里完成选塔、查仓、收藏、道具、ICO、账本和个人页圣殿排序。

- 当前版本：**2.3.96**
- 主文件：[`tinygrail-toolkit.component.js`](./tinygrail-toolkit.component.js)（单文件，无外部依赖）
- 开源协议：MIT

## 安装

1. 打开 Bangumi 的「超合金组件」页面，新建 / 编辑组件；
2. 添加新版本，版本号填 `2.3.96`（每次升级 +0.0.1，不能重复）；
3. 把 `tinygrail-toolkit.component.js` 的全部内容粘进「脚本」框，创建；
   > 嫌长的话可以改用 [`dist/tinygrail-toolkit.component.paste.js`](./dist/tinygrail-toolkit.component.paste.js)：
   > 同一份代码，只是去掉了注释和空行（22,803 行 → 19,909 行），粘贴、审核都轻一些。
4. 启用组件，刷新小圣杯页面，右下角出现「工具箱」浮窗（快捷键 `Alt+T`）。

> 兼容旧版 / 新版小圣杯及 iframe 嵌入页面。停用组件会清掉云设置里的那份数据，重要配置建议另存一份同步码。

## 功能

| 分类 | 能做什么 |
| --- | --- |
| 筛塔 | 按固定资产阈值筛塔，可叠加「塔图是否换过」；**只统计已建成的圣殿（固资上限 ≥ 500）**，未建成的塔不进列表 / 统计 / 复制，统计行会写明排除数量；支持当前角色 / 我的塔 / 角色列表三种来源，大账号分页并发拉、只渲染前 300 行；「角色列表」可勾「只筛自己圣殿」；筛出来是自己的塔时名字右边有图钉，点一下把这座塔排到个人圣殿页第 1 页最前（多座可叠加，图钉变粉再点取消） |
| 持股 | 按等级区间 / 最少持股筛选，每行显示距下一级还差多少股；支持一次搜多个角色名或 ID |
| 复制 ID | 筛塔 / 持股 / 收藏的「复制」统一只导出角色数字 ID（空格分隔、去重）；收藏只导当前收藏夹 |
| 幻想乡 | 查某角色被幻想乡持有的数量与占比 |
| 收藏夹 | 多夹、星标、同角色跨夹合并、标签里直接移夹 / 加夹；一键导入站点收藏（跳过未上市与退市，ST 保留）；同步码 / 云设置跨设备同步 |
| 自动补资 | 固资不足时献祭炮塔自己的持股：1 股补 2 固资；**绝不越过塔上限**（500 上限 / 237 固资 → 只献 131 股到 499，不会把上限撑成 501） |
| 道具 | 标题栏「一键每日任务」：按道具页现成的三套配置依次执行（勾哪项跑哪项），最后自动买 3 次刮刮乐，刮刮乐每次只列当前价格最高的三种；混沌魔方 / 虚空道标 / 鲤鱼之眼批量连用（三种道具的次数各存各的，改一个不影响其它），混沌魔方逐个列出抢到的角色「谁 + 多少股（单价）」；一键冲星；星光碎片燃料可多选、按队列顺序依次消耗，按「目标等级 − 燃料等级」换算固资（同级 1 股 = 1 固资，每差一级减半，最多 32 股 = 1 固资），可从上限以下一次性超充，但当前固资已达 / 超上限时不再补；燃料可按股数从少到多排序，并给出逐只预计固资 |
| 塔图 | 静态图 / 透明 PNG / GIF 换图与直传；旧版（jQuery）页面的塔卡也能贴图（当最上层背景叠上去，站点的 +10 / 收益率标签照常显示），但点开塔图看到的仍是站点原图；粘贴 CDN 或右键复制的图片地址即可换图，也能复制塔图地址（展示用 CDN、提交用 OSS 裸地址）；重复塔按「角色 + 塔主」区分，避免把修改做成复制；「视频」按键跳裁剪工具，GIF 置顶按钮在右下 |
| GIF 封面 | 裁剪浮窗里的「GIF封面」：载入 .gif 后逐帧挑一帧贴成封面（覆盖层夹在塔图与播放键之间，点播放自动隐藏）；「只更换封面」**默认勾上**（只在本机贴图，站点上的原 GIF 一个字节都不动），不勾则贴图 + 原 GIF 整段直交（不重编码）；旧版不支持 GIF 塔图，选帧时给一句提示；当前塔图本身是 GIF 时给一条另存入口（CDN 没开 CORS，读不到字节）；往这个界面里放**静态图**也不退出选帧——单塔勾「只更换封面」就只贴这张图、不勾就直接换塔图，LINK 则默认只贴图（想换静态 LINK 图在普通裁剪里做），勾「另一半」两座塔都贴；来回切「GIF封面」浮窗长度不变 |
| 竞拍 | 新版弹窗里的数量默认填「我已经拍过的股数」，没参与过才是 1 股；旧版默认价按显示的两位小数（低于真实底价时抬一分），底价晚到会自动补上，不再闪一下「₵0.00」 |
| ICO | 参与中的 ICO 按剩余时间排序，目标等级 + 结束前自动补注资，附上市等级对照 |
| 圣殿 | 个人页圣殿置顶 / 置底（最后一页最后一个）、拖拽调序、每行 4/5/6 个（站点重绘也不会跳回 4 列）；**置顶 / 置底 / 调序点完当场重排，不用刷新**（新旧两版都支持）；各级圣殿数量按固资上限分档（500 / 2500 / 12500）；旧版圣殿卡右下角那枚收益率胶囊可换成星之力（紫 ≥1 万 / 黄 / 灰），个人页和角色页看别人的塔都按塔主对号；无缝 link 图、LINK 圣殿左右互换（新版按角色 ID 去重，同一座不记两遍） |
| 账本 | 资金 / 股数 / 固资按来源分类汇总，余额走势、持股排行、道标命中统计；股数分「获得 / 失去 → 类型」两级筛选，排序可正可倒、条数 10~100，角色归属以日志里的 `#ID` 为准（刮刮乐的 RelatedId 会串号）；圣殿只统计损失；另有星之力视角——按时间段从日志累加，或直接读「当前总量」，档位可筛 0~1 万 / 1~5 万 / 5~10 万 / >10 万，表里带角色等级；统计窗口按**自然日**切（第一天 0:00 ~ 最后一天 24:00），可选近 3/7/14/30 天或自定义起止日期；刮刮乐次数按购买次数算（-1000 cc 那条），不按奖励记录条数；统计只增不改：同一范围再点只补新记录（通常 1 个请求），换范围从已读记录里直接筛；单次最多读取 150 页（约 3 万条），撞上限会在状态栏写明 |
| 其它 | 随手记、日夜模式、窗口拖动位置记忆；bgm 右下角工具条里有一键收起悬浮球的开关（收起后 Alt+T 仍能唤回） |

所有联想输入框支持输数字 ID 出候选、一次填多个；圣殿置顶 / 置底的候选只列「自己建过塔」的角色，避免选到没有塔的同名角色。

## 注意

- 道具、冲星、ICO 注资、献祭补资、塔图换图与上传都是**真实操作**，会消耗固资和资金或改动站点图片，点之前看清楚。
- 用地址换图后，站点里的旧底图不会立刻刷新，刷新页面即可看到新图。
- 改「每行几个」要刷新个人页才生效（置顶 / 置底 / 调顺序 / 定位不用，点完当场重排）。
- 账本 / 道具提示「未登录小圣杯或会话已过期」时，多半是 bgm 页面下小圣杯的登录态掉了（或浏览器禁了第三方 Cookie），去小圣杯登录一下再刷新即可。
- 筛选、统计、排序类功能只改你本地看到的画面，不影响他人显示。
