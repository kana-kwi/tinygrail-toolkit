# 小圣杯工具箱 · tinygrail-toolkit

Bangumi「小圣杯」的单文件超合金组件，新旧两版页面通用。一个浮窗里完成选塔、查仓、收藏、道具、ICO、账本和个人页圣殿排序。

- 当前版本：**2.3.11**
- 主文件：[`tinygrail-toolkit.component.js`](./tinygrail-toolkit.component.js)（单文件，无外部依赖）
- 开源协议：MIT

## 安装

1. 打开 Bangumi 的「超合金组件」页面，新建 / 编辑组件；
2. 添加新版本，版本号填 `2.3.11`（每次升级 +0.0.1，不能重复）；
3. 把 `tinygrail-toolkit.component.js` 的全部内容粘进「脚本」框，创建；
4. 启用组件，刷新小圣杯页面，右下角出现「工具箱」浮窗（快捷键 `Alt+T`）。

> 兼容旧版 / 新版小圣杯及 iframe 嵌入页面。停用组件会清掉云设置里的那份数据，重要配置建议另存一份同步码。

## 功能

| 分类 | 能做什么 |
| --- | --- |
| 筛塔 | 按固定资产阈值筛塔，可叠加「塔图是否换过」；支持当前角色 / 我的塔 / 角色列表三种来源，大账号分页并发拉、只渲染前 300 行 |
| 持股 | 按等级区间 / 最少持股筛选，每行显示距下一级还差多少股；支持一次搜多个角色名或 ID |
| 幻想乡 | 查某角色被幻想乡持有的数量与占比 |
| 收藏夹 | 多夹、星标、同角色跨夹合并、标签里直接移夹 / 加夹；一键导入站点收藏（跳过未上市与退市，ST 保留）；同步码 / 云设置跨设备同步 |
| 道具 | 混沌魔方 / 虚空道标 / 鲤鱼之眼批量连用；一键冲星；星光碎片燃料可多选、按队列顺序依次消耗 |
| ICO | 参与中的 ICO 按剩余时间排序，目标等级 + 结束前自动补注资，附上市等级对照 |
| 圣殿 | 个人页圣殿置顶 / 置底（最后一页最后一个）、拖拽调序、每行 4/5/6 个；无缝 link 图、LINK 圣殿左右互换 |
| 账本 | 资金 / 股数 / 固资按来源分类汇总，余额走势、持股排行、道标命中统计 |
| 其它 | 随手记、塔图换图与复制、日夜模式、窗口拖动位置记忆 |

所有联想输入框支持输数字 ID 出候选、一次填多个；圣殿置顶 / 置底的候选只列「自己建过塔」的角色，避免选到没有塔的同名角色。

## 注意

- 道具、冲星、ICO 注资都是**真实操作**，会消耗固资和资金，点之前看清楚。
- 改完「圣殿置顶 / 置底」或每行数量后要刷新个人页才生效。
- 组件只改你本地看到的画面，不改动站点数据，也不影响他人显示。
